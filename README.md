# 🚗 DriveGenius (v1.0.0) — 普通免許 学科試験 本番対策AIトレーナー

[QuaGenius (v2.30)](https://github.com/Tissuesg/ai-quiz-app) をベースにフォークし、**普通自動車第一種運転免許（仮免許・本免許）の学科試験本番**に特化して構築したフロントエンド完結型SPA（シングルページアプリケーション）です。

---

## 🌟 主な機能（本番試験特化）

### 1. 本番試験に完全準拠した出題形式
- **⭕❌ ○×（正誤）問題（1点）**：文章問題・道路標識・道路標示を本番同様に「正しい (○) / 誤り (×)」で即座に判定（キーボード `O / ←`・`X / →`・`Enter` 対応）。
- **🚧 危険予測イラスト 3連○×問題（2点）**：本免学科試験の「イラスト問題（1場面につき3設問・全問正解で2点）」を忠実に再現。

### 2. 道路標識・標示 35種 & 危険予測イラスト 10シーンのSVG内蔵
- 生成AI任せにすると不正確になりがちな日本の道路標識・道路標示（規制標識・指示標識・警戒標識・路面標示）**35種**と、本免危険予測イラスト**10シーン**を鮮明なSVGとして内蔵（[`data/traffic_visuals.js`](./data/traffic_visuals.js)）。
- 標識問題は回答前には正式名称を隠して出題し、回答後に名称を表示します。

### 3. 精査済み問題バンク（63問）＋ AI類題生成のハイブリッド構成
- **APIキーなしですぐに使える精査済み問題バンク（63問）**（[`data/question_bank.js`](./data/question_bank.js)）を収録。
- **AIハルシネーション対策**：AI生成モードでは `TRAFFIC_LAW_REFERENCE`（5m/10m/30m/3秒ルール、普通免許3.5t未満・積載1.2倍改正・特定小型原付等の最新基準）をプロンプトに注入し、Structured Outputs ＆ SVG ID実在バリデーションで誤判定を徹底抑制します。
- **⚠️ ひっかけ・数値ルール特訓モード** / **🌐 Gemini Google検索グラウンディング（最新道交法改正対応）** も搭載。

### 4. 学習効率を最大化する学習プラットフォーム機能
- **4コース × 3階層シラバス網羅マップ**：本免（8分野・54論点）／仮免（5分野・30論点）／標識マスター（3分野・15論点）／危険予測（3分野・12論点）の塗りつぶし進捗＆傾向分析。
- **消化型復習モード**・**⭐ ブックマーク**・**🎓 AI教習指導員への深掘りチャット**・**🔊 TTS解説読み上げ**・**📄 PDF保存/印刷**・**☁️ Googleドライブ自動同期（[`gas/drivegenius_sync.gs`](./gas/drivegenius_sync.gs)）**。

## 🚀 使い方

1. `index.html` をブラウザ（またはローカルHTTPサーバー / GitHub Pages）で開きます。
2. **まずはAPIキー不要**でそのまま「新規問題を出題」を押すと、精査済み問題バンク（63問）から本番形式で演習できます。
3. 無限のAI類題生成や「AI教習指導員」への深掘り質問を利用する場合は、右上の ⚙️ 設定から無料APIキー（Google Gemini推奨）を入力してください。
